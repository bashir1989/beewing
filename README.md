# مدل شبکه عصبی برای تشخیص دودمان بال (C / M / O)

همه نتایج زیر روی پوشه `Normalized_PNG` به دست آمده‌اند: ۶۶۵ تصویر از ۷۲ کلنی (C: ۲۴۷، M: ۱۳۰، O: ۲۸۸). نسبت به نسخه قبلی، هفت تصویر مشکل‌دار حذف و یک تصویر M اصلاح شده است. نتایج قدیمی (۶۷۲ تصویر BMP) در پوشه `archive_bmp_672/` نگه داشته شده‌اند.

## نتیجه روی داده تست بخش اول (۲۰٪، ۱۲۹ تصویر از ۱۵ کلنی)
- دقت برای هر بال: **۹۳.۸٪** (۱۲۱ از ۱۲۹)، ماکرو F1 برابر ۰.۹۳۰
- دقت برای هر کلنی (رأی اکثریت بال‌های همان کلنی): **۱۰۰٪** (۱۵ از ۱۵)

| دودمان | precision | recall | تعداد تست |
|---|---|---|---|
| C | 0.943 | 0.980 | 51 |
| M | 0.947 | 0.857 | 21 |
| O | 0.930 | 0.930 | 57 |

ماتریس درهم‌ریختگی (سطر = واقعی، ستون = پیش‌بینی، ترتیب C، M، O):
```

 [ 3  1 53]]
```

## اعتبارسنجی متقابل ۵بخشی گروهی بر اساس کلنی
| روش | دقت بال | ماکرو F1 | بازیابی M | کلنی درست |
|---|---|---|---|---|
| ResNet18 ازپیش‌آموخته (ImageNet) | 92.9 ± 4.1٪ | 0.919 | 0.831 | 71/72 |
| CNN کوچک از صفر | 91.7 ± 4.2٪ | 0.912 | 0.869 | 69/72 |
| PCA + LDA | 90.2 ± 1.9٪ | 0.889 | 0.808 | 72/72 |
| HOG + SVM | 88.4 ± 2.4٪ | 0.865 | 0.685 | 70/72 |

آزمون مک‌نمار با تصحیح هولم: فقط تفاوت ResNet18 با HOG + SVM معنی‌دار است (p = 0.0012، پس از تصحیح 0.007).

## داده و تقسیم
- تقسیم ۸۰/۲۰ طبقه‌بندی‌شده بر اساس دودمان و گروه‌بندی‌شده بر اساس شماره کلنی (عدد قبل از اولین `-` در نام فایل)، تا هیچ کلنی هم در آموزش و هم در تست نباشد.
- بخش اول: ۴۳۱ آموزش، ۱۰۵ اعتبارسنجی (۱۱ کلنی)، ۱۲۹ تست (۱۵ کلنی). فهرست دقیق فایل‌ها در `results/split.json` است.

## مدل
- یک CNN کوچک (۵ بلوک کانولوشن، حدود ۱.۵ میلیون پارامتر) که از صفر آموزش دیده؛ ورودی خاکستری 320×144.
- افزایش داده: چرخش ±۴ درجه، جابه‌جایی و مقیاس کوچک، تغییر روشنایی و کنتراست.
- AdamW، ۶۰ دوره، وزن‌دهی کلاس‌ها برای جبران کم بودن M.

## اجرا روی کامپیوتر خودتان
```

```
نسخه GPU (روی کارت NVIDIA خیلی سریع‌تر است؛ نسخه CUDA پایتورچ لازم است):
```

python train_wing_cnn_gpu.py --data "E:\ML\subspecies\subspecies Train\Normalized_PNG" --out results
```
- ResNet18: `--pretrained --weights resnet18_a1_0-d63eafa0.pth --epochs 30`
  (وزن‌ها از github.com/huggingface/pytorch-image-models/releases/download/v0.1-rsb-weights/resnet18_a1_0-d63eafa0.pth)
- بخش دیگر اعتبارسنجی متقابل: `--fold 0..4`

## فایل‌ها
- `train_wing_cnn.py` (CPU)، `train_wing_cnn_gpu.py` (GPU): کد آموزش
- `results/`: مدل بخش اول (`best_model.pt`)، گزارش تست، پیش‌بینی هر تصویر، روند آموزش (`history.json`، `run.log`)
- `experiments/`: `baseline_classic.py`، `gradcam.py`، `summarize_cv.py`، `run_all.sh` و نقشه `gradcam_fold0.png`
- `experiments/cv_results/`: نتایج هر بخش برای CNN (بخش‌های ۱ تا ۴؛ بخش ۰ همان `results/` است) و ResNet18، روش‌های کلاسیک و خلاصه `cv_summary.json`
